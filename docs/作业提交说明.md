## 四、教师验收路径（README 可独立复现）

1. `git clone https://github.com/cql123-love/study-task.git`
2. `python -m venv venv && venv\Scripts\activate`
3. `pip install -r requirements.txt`
4. `python app.py` → 浏览器访问 http://127.0.0.1:5000
5. `pytest tests/ -v` → 13 条测试全部通过
6. 或直接访问上表「网站 Web 地址」查看在线版本

## 五、注意事项

- **持久化验收（T10）以本地运行为准**：云端免费实例磁盘为临时盘，重新部署后数据会重置；云端首次启动会自动写入 5 条演示数据，便于直接查看界面效果。
